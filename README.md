# Hub Fora Do Papel

Crie um projeto vazio chamado "hub-fora-do-papel" em Vite + React + TypeScript + Tailwind + shadcn/ui (SPA com Vite, sem TanStack Start e sem renderização no servidor). Não crie telas, banco nem autenticação e não ative o Lovable Cloud; só a estrutura inicial com uma página "Hub Fora do Papel".

This project was built with [Lovable](https://lovable.dev).
